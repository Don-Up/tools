CODE FILLING
使用说明 · Ctrl+H

输入框操作

点击逐字揭示下一个字符
长按 600ms填充当前输入框
Shift+点击填充当前 Tab 所有输入框
Alt+点击填充当前输入框
Ctrl+点击启动 5 分钟倒计时
Ctrl+Shift+点击启动 15 分钟倒计时
Ctrl+Alt+点击启动 2 分钟倒计时
Ctrl+Shift+Alt+点击启动 10 分钟倒计时
中键点击清空输入框及计时器
输入 Nm（如 10m）启动 N 分钟倒计时
按键 `揭示下一个字符（焦点在输入框时）

计时器提示

到点提示输入框变红 + 播放音效 + Tab 标题出现 💡
点击变红的输入框清空输入框及计时器

Tab 操作

点击 Tab切换到该 Tab
Alt+点击重命名 Tab
点击 ×关闭 Tab
点击 + Add Tab新建 Tab
Ctrl+点击 TabTab 内所有输入框启动 5 分钟倒计时
Ctrl+Shift+点击 TabTab 内所有输入框启动 15 分钟倒计时
Ctrl+Alt+点击 TabTab 内所有输入框启动 2 分钟倒计时
Ctrl+Shift+Alt+点击 TabTab 内所有输入框启动 10 分钟倒计时

全局

Ctrl+V粘贴代码（{{ }} 与 ~ ~ 自动转为输入框）
F3切换注释显隐
Ctrl+H显示/隐藏此弹窗
Esc关闭此弹窗
点击标题 "CODE FILLING"清空当前 Tab 所有输入框及计时器
