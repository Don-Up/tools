# MyBatis 苏格拉底式对话教学页 — 设计文档

日期：2026-10-20
产物：`docs/study/mybatis-dialog.html`（单文件、零构建）

## 目标

面向 MyBatis 菜鸟与新手，用「一问一答」的苏格拉底式对话体逐句推进学习；每页一个知识点，由易到难；配合图形动画、代码逐步展示与末尾测验，达成快速入门。

## 技术栈

全部 CDN 引入，无构建步骤，双击即可打开：

| 依赖 | 地址 | 用途 |
|---|---|---|
| Tailwind CSS 3 (Play CDN) | `https://cdn.tailwindcss.com` | 布局与工具类 |
| DaisyUI 4 (full.min.css) | `https://cdn.jsdelivr.net/npm/daisyui@4.12.10/dist/full.min.css` | 组件样式，`data-theme="night"` 深色主题 |
| Alpine.js 3 | `https://cdn.jsdelivr.net/npm/alpinejs@3.14.1/dist/cdn.min.js` | 状态与渲染 |
| Anime.js 3.2.2 | `https://cdn.jsdelivr.net/npm/animejs@3.2.2/lib/anime.min.js` | 动画 |

DaisyUI 通过独立 CSS 引入，主题由 `<html data-theme="night">` 选择，不依赖 Play CDN 的插件加载。

## 页面布局

三栏栅格（窄屏纵向堆叠，由 Alpine 断点控制）：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏：MyBatis 入门 · 第 N/12 课 · 进度条 · 朗读总开关       │
├────────────┬───────────────────────────┬─────────────────────┤
│ 左栏        │ 中栏：对话舞台               │ 右栏：可视化演示       │
│ ① 课时目录  │ 师生气泡交替，逐句展开       │ 关系图 / 流程图        │
│ ② 学生音色  │ 底部：◀ 下一句 / 下一课 ▶     │ 数据（表格/柱状）      │
│ ③ 老师音色  │ 每句旁 🔊 可单独重听          │ 代码（逐行显现）        │
│ ④ 语速条    │                            │ ▶ 手动触发动画        │
└────────────┴───────────────────────────┴─────────────────────┘
```

### 左栏
- 课时目录：12 项，可折叠、可点击直接跳课，当前课高亮
- 学生音色下拉、老师音色下拉：列出 `speechSynthesis.getVoices()` 全部音色
- 语速条：0.5 – 2.0，步长 0.1
- 选择结果存 `localStorage`

### 中栏
- 对话气泡：学生左对齐（不同色），老师右对齐（另一种色）
- 每次只展开一句；展开动画用 Anime.js（Y 轴位移 + 透明度）
- 每句左侧一个 🔊 按钮，单独重听该句
- 底部按钮：对话未完显示「下一句 ↓」，对话已完变为「下一课 →」

### 右栏
每课有且仅有一种主视觉，按类型渲染：
- `relation` 关系图：节点卡片 + SVG 连线，Anime 描边 + 节点弹入
- `flow` 流程图：分步推进，每步高亮
- `data` 数据演示：表格逐行插入 / 柱状图增长
- `code` 代码块：按行 stagger 显现，提供「▶ 逐步播放」与「⏩ 全显」

动画一律手动触发（按钮），不自动播放。

## 交互与键盘

| 按键 | 行为 |
|---|---|
| `↓` | 展开下一句对话，并朗读 |
| `↑` | 收起上一句（重新可听） |
| `←` | 上一课 |
| `→` | 下一课 |

翻页时中断当前朗读；切课后对话回到未展开状态（测验课除外，见下）。

## TTS 机制

- 使用浏览器 `speechSynthesis` / `SpeechSynthesisUtterance`
- 音色选择：学生优先匹配名字含 `Xiaoxiao` 的音色；老师优先含 `Yunjian` 的音色；两者都找不到时，依次退到任意 `zh-CN` 音色 → `getVoices()[0]` → 默认
- 顶层下拉允许手动覆盖自动选择
- 语速条控制 `utterance.rate`
- **符号转文本**：`toSpeech(text)` 用转换表把符号替换为口语说法
  - `<` → 「左尖括号」、`>` → 「右尖括号」
  - `#{}` → 「占位符」、`${}` → 「美元占位符」
  - `->` → 「指向」、`=>` → 「映射到」
  - `&&` → 「并且」、`||` → 「或者」、`!=` → 「不等于」
  - `*` → 「星号」、`()` → 「括号」、`/` → 「斜杠」
  - `@Param` → 「Param 注解」、`${}` 拼接形式额外强调「这是直接字符串替换，有注入风险」
- 对话正文本身写成口语（比喻为主、少用术语），代码块不进朗读
- 展开即朗读；顶部有朗读总开关；重听按钮只读当前句
- 语音列表异步加载（`voiceschanged` 事件后刷新下拉）

## 内容模型

```js
{
  id: 1,
  title: 'MyBatis 是什么',
  goal: '一句话说清它替你省掉了什么',
  turns: [
    { role: 'student', text: '我写 JDBC 觉得好啰嗦……' },
    { role: 'teacher', text: '你被 JDBC 样板代码拖累啦。', art: 'compare' }
  ],
  art: { type: 'relation', ... }
}
```

- `turns[].art` 可选，指定该句触发的右栏高亮/动画
- `art.type` 决定右栏渲染分支

## 12 课大纲

知识点先行（前 7 课每课一个核心概念），再进入复杂场景（8–11 课），末课测验。

| # | 主题 | 右栏演示 |
|---|---|---|
| 1 | MyBatis 是什么：对比 JDBC 样板代码 | 写 SQL vs 映射 对比流程 |
| 2 | 核心对象：SqlSessionFactory / SqlSession | 生命周期关系图 |
| 3 | 两种开发方式：XML 映射 vs 注解 | 同一功能两种写法代码对照 |
| 4 | 第一个 Mapper：增删改查 | 代码逐行显现 + 表格插入动画 |
| 5 | 参数传递：单参 / `@Param` / 多参 | 参数如何拼进 SQL 的流程图 |
| 6 | 查询结果：resultType 与返回对象 | 单对象 vs 列表数据演示 |
| 7 | resultMap：列名对不上时的映射 | 字段映射连线图 |
| 8 | 动态 SQL：where / if / set | 条件组合动画 |
| 9 | foreach：IN 查询与集合参数 | 列表展开动画 |
| 10 | 关联映射：一对多 / 嵌套结果 | 部门→员工 树状展开 |
| 11 | 场景：分页插件 + 事务 + 缓存概览 | 拦截器链流程图 |
| 12 | 测验：6 题易混单选 + 即时解析 | 答题卡与成绩 |

## 对话写法

两条回路贯穿全部课程：

1. **问题驱动**：学生先抛出典型困惑（例：「不写 XML 能不能用？」），老师再引出知识点。
2. **犯错-纠错**：学生先用错的方式表述或写代码，老师指出错在哪、为什么错。

学生发言占比约 40%，避免单方面宣讲。

## 测验（第 12 课）

- 6 道四选一，全部考易混点（`#{}` vs `${}`、`resultType` vs `resultMap`、一级/二级缓存、`@Param` 缺失的后果、`selectOne` vs `selectList`、XML 与注解优先级）
- 每题答完立即显示对错 + 老师的一段解析（同时朗读）
- 全部答完给总评：得分、错题对应的课号与复习建议
- 测验课不受「逐句展开」控制：进入后直接展示 6 题卡片

## 边界与不做的事

- 不引入后端服务、构建工具或 npm 依赖
- 不做用户账号、进度持久化到服务器（仅 `localStorage` 存音色与语速）
- 不覆盖 MyBatis-Plus 实战、源码级缓存机制、Spring Boot 自动配置细节
- 语音依赖操作系统已安装的中文音色；缺失时页面仍可正常阅读
