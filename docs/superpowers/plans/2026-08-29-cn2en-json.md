**Goal:** 为 `cn2en-json.html` 建立最小可运行骨架：暗黑模式空页面 + 全局 Ctrl+V 监听器，读取剪贴板文本并输出到 console。

**Architecture:** 单文件 HTML，内联 CSS 设置深色 body，内联 JS 在 document 上注册 keydown 监听器，检测 Ctrl+V 后调用 `navigator.clipboard.readText()` 并 `console.log`。无组件、无依赖、无构建步骤。

**Tech Stack:** 纯 HTML/CSS/JS（vanilla），使用浏览器原生 Clipboard API。

## Task 1: 创建 HTML 骨架与暗黑模式

**Files:**
- Modify: `cn2en-json.html`（替换空文件内容）

- [ ] **Step 1: 写入 HTML 骨架与深色 body 样式**

将 `cn2en-json.html` 内容替换为：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>cn2en-json</title>
    <style>
        body {
            margin: 0;
            min-height: 100vh;
            background-color: #121212;
            color: #e0e0e0;
            font-family: Arial, sans-serif;
        }
    </style>
</head>
<body>
<script>
    document.addEventListener('keydown', async function (e) {
        if (e.ctrlKey && !e.shiftKey && !e.altKey && e.code === 'KeyV') {
            e.preventDefault();
            try {
                const text = await navigator.clipboard.readText();
                console.log('剪贴板文本:', text);
            } catch (err) {
                console.error('读取剪贴板失败:', err);
            }
        }
    });
</script>
</body>
</html>
```

## Task 2: 手动验证 Ctrl+V 监听器

**Files:**
- 无文件修改（仅验证）

- [ ] **Step 1: 准备测试剪贴板内容**

复制任意文本到剪贴板（例如在浏览器地址栏选中一段 URL，或在任意应用中 Ctrl+C 复制一段文字）。

- [ ] **Step 2: 在浏览器中打开页面并打开 DevTools Console**

打开 `cn2en-json.html`，按 F12 打开开发者工具，切换到 Console 面板。

- [ ] **Step 3: 按下 Ctrl+V**

确认页面或 DevTools 拥有焦点后，按下 Ctrl+V。

预期 Console 输出：`剪贴板文本: <你刚才复制的文本>`。如果没有输出，检查：
- 剪贴板权限是否被拒绝（首次调用会弹出权限请求）
- 文件是否通过 `file://` 协议打开（部分浏览器在非 HTTPS / 非 localhost 时会拒绝剪贴板 API）
- 是否有其他按键组合被同时按下

- [ ] **Step 4: 测试错误处理路径**

清空剪贴板（任意应用里选中并删除），再次按 Ctrl+V。

预期 Console 输出 `读取剪贴板失败: ...` 或静默（取决于浏览器是否将空剪贴板视为错误）。

- [ ] **Step 5: 测试修饰键互斥**

按住 Shift+Ctrl+V 或 Alt+Ctrl+V。

预期：无 console 输出，证明 `!shiftKey && !altKey` 条件生效。
