# 朗读选中文字(Edge 扩展)

选中网页上的文字,按 **Alt+2** 就念出来。点工具栏图标可以设置语音和速度。

用的是页面自己的 Web Speech API(`speechSynthesis`),所以语音就是系统里装好的那批
(和 `cn2en-json.html` 里用的是同一批),不需要额外的后台进程。

## 安装(Edge)

1. 地址栏打开 `edge://extensions`
2. 左下角打开「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选到这个 `edge-read-aloud` 文件夹
5. 想在本地 html 文件上用的话,进扩展详情把「允许访问文件网址」打开

## 用法

| 操作 | 结果 |
| --- | --- |
| 选中文字 → `Alt+2` | 朗读选中内容(输入框、文本域里选中的也读) |
| 点工具栏图标 | 打开设置面板 |
| 面板里「试听」 | 用当前设置念一句测试语音 |
| 面板里「朗读选中」 | 念当前页面选中的文字 |
| 面板里「停止」 | 停下正在念的 |

设置面板能调:**语音**(系统语音列表)、**速度**(0.5–2.0)、**音调**(0.5–1.5)、**音量**(0–1)。
设置存在 `chrome.storage.local`,改完立刻对当前页面生效,不用刷新。

## 说明

- 没选中文字时按 Alt+2 不会朗读,也不会拦掉页面自己的 Alt+2。
- 拿到文字后选区会被清掉:正文的高亮消失,输入框里的光标缩到选区末尾。
- 连按几次会重新念当前选中的内容(不会排成一长串)。
- 语音列表是空的 = 系统里没装语音包。Windows:设置 → 时间和语言 → 语音 → 添加语音。
- 页面自己在用 TTS 时(比如 `focus-json` 页),Alt+2 会把页面的朗读一起停掉。
