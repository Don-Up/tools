### 面试黄金流程：解题四步法话术模板

在面试中，不要直接埋头写代码。按照以下步骤走，能让面试官对你的思路一目了然：

1. **Clarify（确认题意）**
   - *“Let me make sure I understand the problem correctly...”*
   - *“What happens if the input is empty?”*

2. **Propose（提出思路）**
   - *“I have a few approaches in mind. First, a brute force method would be..., but I think we can optimize it using...”*
   - *“The intuition behind my approach is...”*

3. **Code（编写代码）**
   - *“I'll start by initializing the necessary variables...”*
   - *“Now I'll write the main loop...”*
   - *“Let me walk through the code with a simple input...”*

4. **Review & Analyze（复查与分析）**
   - *“Let me double-check the edge cases...”*
   - *“The time complexity is O(n) and space complexity is O(1).”*

### 完整标准话术示例（可直接背诵）

> *“Before we start, I'd like to clarify a few things: Is the input array sorted? How should we handle duplicates?*

> *The core idea of my approach is to use a **two-pointer** technique to find the pair. We'll initialize one pointer at the start and one at the end. If the sum is too small, we move the left pointer right; if it's too large, we move the right pointer left. This runs in linear time.*

> *Let me walk you through the code. I'll **initialize** the pointers, then **iterate** while `left < right`. We'll **compute** the current sum and **compare** it with the target. Finally, we **return** the pair.*

> *Let's do a **dry run** with the given example. If we don't find the pair, we return `null`. The **time complexity** is O(n) because we scan the array once, and the **space complexity** is O(1) since we're not using extra space.”*


### 图表：复杂度关键词与面试官期望值的对应关系

| 问题规模（n） | 期望的算法复杂度 | 关键词（回答时使用） |
| :--- | :--- | :--- |
| `n <= 10^6` | O(n) 或 O(n log n) | *linear, linearithmic, optimal* |
| `n <= 10^4` | O(n^2) 可能接受（通常需要优化） | *quadratic, brute force* |
| `n <= 30` | 指数复杂度（如 O(2^n)）可能接受 | *backtracking, exhaustive search, NP-hard* |
