## 程度高（very / highly / extremely）

- 非常，通用口语，面试可用，技术写作尽量少用

- 高度地、非常，技术文本高频，修饰抽象形容词

  - 该实现针对吞吐量做了**高度**优化。

- 极其，程度极强，强调超出正常范围

  - 该操作带来**极其**高的 CPU 开销。


## 本质上（fundamentally / essentially / basically）

  - 该方案和旧设计在**根本上**完全不同。

- 实质上、本质上，抛开表象看核心属性
  - These two algorithms are **essentially** identical.
  - 这两个算法**实质上**是相同的。

- 基本上、大体上，简化概括，省略次要细节

  - **基本上**，这个函数用来缓存计算结果。


## 可能（likely / probably / possibly / perhaps）

  - 该瓶颈**大概**是锁竞争造成的。

- 有可能，概率偏低，仅仅存在可能性
  - This approach can **possibly** reduce memory overhead.
  - 这个方案**有可能**降低内存开销。

- 也许，偏口语、委婉推测，语气最弱
  - **Perhaps** we should consider an alternative solution.
  - **也许**我们应当考虑备选方案。
