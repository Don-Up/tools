## 特意（make a point to / go out of one's way to）

- 刻意提醒自己去做重要的事，确保不遗漏，首选
  - I **make a point to** review every PR before it's merged.
  - 我**特意**要求自己在每个 PR 合并之前都做 review。

- 宁可自己多费周折也要帮助别人，带有"热心、体贴"意味
  - She **went out of her way to** help me debug the issue.
  - 她**不惜麻烦地**帮我调试了这个问题。


## A与B相同（is the same as / is almost the same as / is identical to）

- 最通用，语义宽泛，指行为、效果、概念相似
  - The behavior **is the same as** using var.
  - 效果和使用 var **一致**。

- 大体相近但不完全等同，存在细微差别
  - Its syntax **is almost the same as** regular functions.
  - 它的语法和普通函数**大体相近**。

- 完全一模一样，无任何区别，语气更强更严谨
  - Two primitive values **are identical to** each other.
  - 两个原始值**完全相等**。


## 压力大（stressful / stressed / under a lot of stress / under heavy load）

- 事物本身会制造压力，修饰场景、任务、条件
  - This **stressful** workload may exhaust memory resources.
  - 这种**高压力的**工作负载可能耗尽内存资源。

- 人或系统自身被压力压得紧绷不堪
  - The worker process gets **stressed out** during traffic surge.
  - 流量暴涨期间工作进程变得**不堪重负**。

- 承受巨大压力，抽象压力，人、系统都能用
  - The coordination service is **under a lot of stress** at peak hour.
  - 高峰时段协调服务**承受很大压力**。

- 工程专用，特指CPU/IO/请求量带来的高负载
  - Nodes behave abnormally **under heavy load**.
  - 节点**在高负载下**表现异常。


## 有空（be free / be available / have some bandwidth）

- 没有被占用、闲置释放出来，侧重"不忙、没负载"
  - The thread pool worker is **free** to accept new tasks.
  - 线程池工作线程**空闲**，可以接收新任务。

- 处于就绪可用状态，可以对外提供服务，工程高频
  - The replica node is **available** after health-check passes.
  - 健康检查通过后，副本节点变为**可用**。

- 比喻用法，指人或系统还有剩余处理余力
  - The team does not **have some bandwidth** for another feature this sprint.
  - 这个迭代团队没有**余力**承接另一个新特性。


## 专用于/专属于（be dedicated to / be exclusive to）

- 资源被分配专门用来做某事，侧重用途，不强制排他
  - This thread is **dedicated to** handling IO events.
  - 该线程**专用于**处理 IO 事件。

- 专属于某一方，排他独占，别人不能访问或使用
  - This memory pool is **exclusive to** the high-priority worker.
  - 该内存池**专属于**高优先级工作线程。


## 作用/原理（its role is to / it works by）

- 核心作用、承担的职能是什么
  - **Its role is to** store primitive values.
  - **它的作用是**存放原始类型值。

- 依靠什么原理运作、通过何种方式实现效果
  - **It works by** maintaining references to outer variables.
  - **它依靠**持续持有外层变量的引用实现功能。


## 把...当作...（treat A as B / regard A as B / mistake A for B）

- 主观主动归类、当成...处理，实操层面，技术口语最高频
  - JS **treats** null **as** an object.
  - JavaScript **把** null **当作**对象。

- 观念、理论层面的认知，书面感更强
  - Many developers **regard** closures **as** a hard concept.
  - 很多开发者**将**闭包**视作**难点。

- 误把A当成B，错误认知，自带否定色彩
  - People often **mistake** null **for** undefined.
  - 人们经常**把** null **误认成** undefined。


## 在...背景/场景中（in the context of / in scenarios with）

- 宏观背景、理论语境，偏体系、大前提
  - **In the context of** distributed systems, consistency always brings trade-offs.
  - **在分布式系统的背景下**，一致性总会带来取舍。

- 具体业务场景，后接该场景的具体条件特征
  - **In scenarios with** massive small packets, batch processing improves throughput.
  - **在具备大量小数据包的场景下**，批处理可以提升吞吐。
