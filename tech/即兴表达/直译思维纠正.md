
1. 今天早上: today's morning => this morning
2. 这几天的努力: these days' hard work => a few days of hard work
3. 没接到电话: not receive the call  => miss the call
4. 预期的QPS大概是多少: how much is the expected QPS roughly => what's the rough expected QPS(优先用what而不是how)
5. 今天难得休息: ? => It's a rare day off today
6. 我们距离发布还有2天: ? => we’re two weeks away from release

## 处理无主语
1. 如果明天不下雨的话: If **it** doesn't rain tomorrow
