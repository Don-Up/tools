## 表示肯定（that's true / spot on / right on）

- 没错、确实如此，认同对方说的事实或观点，最通用中性
  - "The build is failing again." — **That's true**, let's check the logs.
  - "构建又失败了。" — **没错**，我们看看日志。

- 一针见血、完全正确，对方的判断精准命中了要害
  - Her analysis of the memory leak was **spot on**.
  - 她对内存泄漏的分析**一针见血**。

- 说得太对了、没错没错，强烈赞同，带有热情共鸣
  - "We should prioritize fixing the flaky tests first." — **Right on**! I've been saying that for weeks.
  - "我们应该优先修复那些不稳定的测试。" — **说得太对了**！我已经说了好几周了。


## 不能/做不到（can't / can barely / fail to / be unable to）

- 不能、没法，明确不具备能力或条件，最直接通用
  - I **can't** access the staging environment right now.
  - 我现在**没法**访问 staging 环境。

- 几乎不能、勉强才能，能力接近极限，差一点就不行
  - The server **can barely** handle the current traffic.
  - 这台服务器**勉强才能**扛住当前的流量。

- 未能，应该做却没做到，常带失败或疏忽意味
  - The build **failed to** complete due to a timeout.
  - 构建**未能**完成，因为超时了。

- 无法、无能力，受客观或主观原因限制而无法，最正式中性
  - We **were unable to** replicate the issue in the test environment.
  - 我们**无法**在测试环境中复现该问题。


## Fall（fall down / fall apart / fall short / fall out）

- 执行出错、出岔子，在某个环节或步骤上出问题，局部故障
  - The deployment **fell down** at the database migration step.
  - 部署在数据库迁移这一步**出岔子**了。

- 彻底崩溃、散架，整体失去结构，完全无法运作
  - The whole system **fell apart** after the config change.
  - 配置变更后整个系统**彻底崩溃**了。

- 未达标、达不到，未能达到预期目标标准或期望
  - We **fell short** of our sprint velocity target.
  - 我们没有达到冲刺速度目标——**差了一点**。

- 闹掰、失去联系，人际关系破裂或失去同步
  - The PM and the tech lead **fell out** over the deadline.
  - PM 和技术负责人因为截止日期**闹掰**了。


## End up（end up doing / end up with / end up in / end up being）

- 到头来做了、最终做出某动作，强调动作结果
  - Without proper throttling, clients **end up retrying** aggressively.
  - 缺少合理限流时，客户端到头来会**疯狂重试**。

- 最终得到、最终拥有，后面接事物数据结果对象
  - We may **end up with** duplicate records after network retries.
  - 经过网络重试之后，我们可能最终**得到**重复的记录。

- 最终落入、最终处于某处，后面接地点容器状态
  - Invalid messages **end up in** the dead-letter queue.
  - 无效消息最终**落入**死信队列。

- 最终变为、到头来处于某状态，后面接形容词/名词
  - This temporary workaround **ends up being** the main logic.
  - 这个临时的变通方案到头来**变成了**主体逻辑。


## Good/Better/Best（be good for / be better for / be best for）

- 适合，对...有好处，中性无对比，仅描述适用性
  - Arrays **are good for** sequential access.
  - 数组**适合**顺序访问。

- 更适合，二者或多者之间做比较
  - Map **is better for** frequent key-value lookups than plain objects.
  - 相比于普通对象，Map **更适合**频繁键值查找。

- 最适合，三者及以上全部选项中的最优选择
  - A hash table **is best for** fast random-key lookup.
  - 哈希表**最适合**按键快速随机查找。


## Sign系列（sign up / sign in / sign on / sign out / sign off）

- 注册，用户首次提供凭证建立账户
  - New users can **sign up** using their email or Google account.
  - 新用户可以使用邮箱或 Google 账户**注册**。

- 登入、登录，使用已有凭证进行身份验证进入系统
  - Please **sign in** to access your dashboard.
  - 请**登录**以访问您的仪表盘。

- 登入，极其罕见的变体，几乎等同于 sign in
  - We use SSO (**Single Sign-On**) for enterprise authentication.
  - 我们使用单点登录（SSO）进行企业认证。

- 登出、退出，主动结束会话、清除凭证
  - Don't forget to **sign out** when you're using a shared device.
  - 使用公用设备时别忘了**登出**。

- 下线、退出、批准，在项目管理中指正式批准
  - The manager needs to **sign off** on the deployment plan.
  - 经理需要**批准**这个部署计划。


## 已经（be already / have already / have been / have + got/grew/become）

- 当前状态，此刻已经是了
  - The server is **already** online.
  - 服务器**已经**在线了。

- 主动完成，某人已经执行了某个动作
  - I have **already** merged the PR.
  - 我**已经**合并了 PR。

- 被动完成，某个操作已经被执行
  - The bug has **been** fixed.
  - 这个 bug **已经被**修复了。

- 发生了质变，状态从 A 变成了 B
  - The project has **grown** too complex.
  - 项目**已经变得**过于复杂了。


## 从来没有（has never been / have never / have never been）

- 代码从未被调用过
  - The code **has never been** called.
  - 代码**从未被**调用过。

- 从没尝试过
  - I **have never** tried that tool.
  - 我从**没尝试过**那个工具。

- 从未去过那里
  - I **have never been** there.
  - 我**从未去过**那里。

- 我从来没有快乐过
  - I **have never been** happy.
  - 我**从来没有**快乐过。


## 更...的是（What's + 比较级 / Even more + 形容词 / More + 副词）

- 更糟的是，后面接完整句子
  - **What's worse**, the build failed.
  - **更糟的是**，构建失败了。

- 更重要的是，后面接名词
  - **Even more critical** is the performance impact.
  - **更关键的是**性能影响。

- 更重要的是，后面接完整句子
  - **What's even more terrifying** is that we found...
  - **更可怕的是**，我们发现了...

- 更重要的是，副词引导
  - **More importantly**, we must ...
  - **更重要的是**，我们必须...


## 随着...（with / as）

- 随着，介词，后接名词短语，不能接完整句子
  - **With** the growth of concurrent requests, latency rises gradually.
  - **随着**并发请求的增长，延迟逐步上升。

- 随着，连词，后接完整句子
  - **As** concurrent requests grow, latency rises gradually.
  - **随着**并发请求增长，延迟逐步上升。


## 即将（will / be going to / be about to / on the verge of）

- 将要、会，通用将来时，技术文档最常用
  - The node **will** reject requests once the threshold is reached.
  - 一旦达到阈值，该节点**将会**拒绝请求。

- 将要、打算，已有迹象表明即将发生
  - The replica **is going to** perform a full-sync operation.
  - 该副本**即将**执行一次全量同步操作。

- 即将、马上就要，极近的将来，时间间隔极短
  - The transaction **is about to** commit.
  - 事务**马上就要**提交。

- 濒临、即将到临界点，处在发生事件的临界边缘
  - The cluster is **on the verge of** resource exhaustion.
  - 集群**即将到达**资源耗尽的临界点。


## 可能（can / may / might）

- 能够、可以，客观上有能力有可能性
  - Heavy writes **can** trigger disk throttling.
  - 大量写入**能够**触发磁盘限流。

- 可能、也许，正式书面客观潜在可能性
  - The operation **may** fail under extreme concurrency.
  - 该操作在极端并发场景下**可能**失败。

- 也许、或许，可能性最低，推测性更强
  - The bottleneck **might** come from lock contention.
  - 瓶颈**或许**来自锁竞争。


## 无（no + 名词 / nothing + 形容词 / without / with no / -free / -less）

- 没有...，直接否定名词，简洁书面
  - There is **no** available buffer.
  - **没有**可用缓冲区。

- 什么都不...，代词，形容词后置修饰
  - **Nothing** useful can be retrieved from stale cache.
  - 从过期缓存中取不到**任何**有用的数据。

- 不具备、不经过，介词，描述伴随条件
  - Process requests **without** extra copying.
  - 处理请求，**不做**额外拷贝。

- 同 without，语气略重
  - This algorithm runs **with no** blocking operations.
  - 该算法运行时**无**阻塞操作。

- 无...的，免除有害或多余事物
  - **lock-free** 无锁；**alloc-free** 无分配

- 缺少...的，本身固有但缺失
  - **memory-less** 无状态无记忆


## 的（of / 's / for / from / 名词拼接）

- <通>：的，表归属、属性、组成、数量，无生命实体首选
  - the scope **of** the function
  - 函数**的**作用域

- <通>：的，有生命对象所有格，技术中少数专有名称可用
  - **React's** rendering mechanism
  - React **的**渲染机制

- <通>：的，表对象、用途、适配目标
  - a tool **for** data parsing
  - 用于解析数据**的**工具

- <通>：的，表来源、出处
  - data loaded **from** the server
  - 从服务器获取**的**数据

- <通>：的，用名词直接拼接作定语，表用途或分类，简洁地道
  - a **database** connection
  - 数据库**的**连接 / 数据库连接

  - **production** environment variables
  - 生产环境**的**变量 / 生产环境变量

  - **error** handling logic
  - 错误处理**的**逻辑 / 错误处理逻辑
