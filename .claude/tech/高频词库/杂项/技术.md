# 函数相关

| 分类         | 中文术语    | 英文术语                        | 核心含义 / 代码讲解场景示例                                                                       |
| :--------- | :------ | :-------------------------- | :------------------------------------------------------------------------------------ |
| **函数定义**   | 函数 / 方法 | Function / Method           | 一段可复用的代码块。 <br> *This function calculates the total price.*                           |
|            | 函数签名    | Function Signature          | 函数名 + 参数列表 + 返回类型。 <br> *The function signature is `getUser(id: int): User`.*         |
|            | 函数体     | Function Body               | 函数内部的具体实现代码。 <br> *The function body contains the core logic.*                        |
|            | 声明      | Declaration                 | 声明函数的存在（不包含实现）。 <br> *We need to declare this function in the header file.*           |
|            | 定义      | Definition                  | 声明 + 完整实现。 <br> *The function definition is in the source file.*                      |
| **参数相关**   | 参数      | Parameter                   | 函数定义时的形式参数。 <br> *This function takes two parameters.*                                |
|            | 实参      | Argument                    | 调用函数时传入的实际值。 <br> *We passed the user ID as an argument.*                             |
|            | 可选参数    | Optional Parameter          | 调用时可省略的参数。 <br> *The timeout is an optional parameter.*                               |
|            | 默认参数    | Default Parameter           | 有默认值的参数。 <br> *This parameter has a default value of 10.*                             |
|            | 位置参数    | Positional Argument         | 按位置顺序传入的参数。 <br> *Positional arguments must be in the correct order.*                 |
|            | 关键字参数   | Keyword Argument            | 按参数名指定的参数。 <br> *We can pass keyword arguments to improve readability.*               |
|            | 可变参数    | Variadic Parameter / \*args | 可接受任意数量参数。 <br> *This function accepts variadic arguments.*                           |
|            | 参数列表    | Parameter List              | 所有参数的集合。 <br> *The parameter list is getting too long.*                               |
| **调用相关**   | 函数调用    | Function Call / Invocation  | 执行函数。 <br> *We call this function to get the data.*                                   |
|            | 调用栈     | Call Stack                  | 函数调用时的执行栈。 <br> *The call stack shows the sequence of function calls.*                |
|            | 递归调用    | Recursive Call              | 函数调用自身。 <br> *This function uses recursive calls to traverse the tree.*               |
|            | 回调函数    | Callback Function           | 作为参数传入、稍后调用的函数。 <br> *We pass a callback to handle the response.*                     |
| **返回值**    | 返回值     | Return Value                | 函数执行后返回的结果。 <br> *This function returns a boolean value.*                             |
|            | 返回类型    | Return Type                 | 返回值的数据类型。 <br> *The return type is `Promise<string>`.*                                |
|            | 返回语句    | Return Statement            | 函数中返回结果的语句。 <br> *The return statement exits the function immediately.*               |
|            | 提前返回    | Early Return                | 在函数中间提前返回。 <br> *We use early return to handle edge cases.*                           |
|            | 无返回值    | Void / No Return            | 函数不返回任何值。 <br> *This function returns void.*                                          |
| **数据流转**   | 传参      | Pass Arguments              | 把值传给函数。 <br> *We pass the config object to the function.*                             |
|            | 按值传递    | Pass by Value               | 传递值的副本，原值不受影响。 <br> *Primitive types are passed by value.*                            |
|            | 按引用传递   | Pass by Reference           | 传递引用，修改会影响原值。 <br> *Objects are passed by reference in JavaScript.*                   |
|            | 赋值      | Assignment                  | 把值赋给变量。 <br> *We assign the return value to a variable.*                              |
|            | 解构赋值    | Destructuring Assignment    | 从对象/数组中提取值并赋值。 <br> *We use destructuring to extract the user data.*                  |
|            | 传入      | Pass In                     | 把数据传入函数。 <br> *We pass in the configuration as an argument.*                          |
|            | 传出      | Pass Out / Return Out       | 把结果传出来。 <br> *The function passes out the computed result.*                           |
| **作用域与状态** | 局部变量    | Local Variable              | 函数内部定义的变量。 <br> *This is a local variable scoped to the function.*                    |
|            | 全局变量    | Global Variable             | 函数外部定义的变量。 <br> *Avoid using global variables inside functions.*                      |
|            | 闭包      | Closure                     | 函数 + 其词法环境的组合。 <br> *This closure captures the outer variable.*                       |
|            | 副作用     | Side Effect                 | 函数对外部状态的影响。 <br> *This function has no side effects. It's pure.*                      |
|            | 纯函数     | Pure Function               | 无副作用，相同输入总是相同输出。 <br> *Pure functions are easier to test.*                            |
| **高阶概念**   | 高阶函数    | Higher-Order Function       | 接收函数作为参数或返回函数的函数。 <br> *Higher-order functions are common in functional programming.* |
|            | 函数式编程   | Functional Programming      | 以函数为核心的编程范式。 <br> *We use map, filter, and reduce in functional programming.*         |
|            | 方法链     | Method Chaining             | 连续调用多个方法。 <br> *Method chaining makes the code more readable.*                        |
|            | 重载      | Overloading                 | 多个同名函数，参数不同。 <br> *Function overloading is supported in TypeScript.*                  |
|            | 重写      | Override                    | 子类重新定义父类的方法。 <br> *We override the parent method in the child class.*                 |
| **常见动作**   | 调用      | Call / Invoke               | 执行函数。 <br> *Call the function to get the result.*                                     |
|            | 执行      | Execute / Run               | 运行函数。 <br> *The function executes the query.*                                         |
|            | 返回      | Return                      | 从函数中返回。 <br> *Return the result immediately.*                                         |
|            | 传入      | Pass In                     | 把参数传进去。 <br> *Pass in the required arguments.*                                        |
|            | 提取      | Extract                     | 从函数中提取逻辑。 <br> *Extract this logic into a separate function.*                         |
|            | 重构      | Refactor                    | 改进函数内部结构而不改变行为。 <br> *We need to refactor this function to make it more readable.*    |
# 技术文档常用复合形容词

#### 1. 时空 / 范围（Time & Scope）

| 复合形容词                  | 核心含义           | 技术场景例句                                                               |
| :--------------------- | :------------- | :------------------------------------------------------------------- |
| **End‑to‑End**         | 端到端的（涵盖完整流程）   | *We need **end-to-end** tests to verify the entire payment flow.*    |
| **Point‑to‑Point**     | 点对点的（直连）       | *We use **point-to-point** integration instead of a message bus.*    |
| **On‑the‑Fly**         | 即时/动态的（边运行边生成） | *The image is resized **on the fly** by the CDN.*                    |
| **Just‑in‑Time (JIT)** | 即时编译的（需要时才做）   | *The JVM uses **just-in-time** compilation to optimize performance.* |
| **Up‑to‑Date**         | 最新的（已同步/已更新）   | *Make sure your local branch is **up to date** with main.*           |
| **Out‑of‑Date**        | 过时的（需要更新）      | *The SSL certificate is **out of date**. We need to renew it.*       |
| **Day‑to‑Day**         | 日常的            | *This is a **day-to-day** task for the DevOps team.*                 |

| **Low‑Latency** | 低延迟的 | *This is a **low-latency** trading system.* |
| **Mission‑Critical** | 任务关键的（核心业务） | *The payment service is **mission-critical**.* |

# 状态与异常术语

#### 1. 正常 / 就绪（Healthy & Ready）
| 术语 | 词性 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **Up / Running** | 形容词 | 正常运行中 | *The service is **up and running** on port 8080.* |
| **Available** | 形容词 | 可用的（能接受请求） | *The database is **available** for connections.* |
| **Ready** | 形容词 | 就绪的（已准备完毕） | *The container is **ready** to serve traffic.* |
| **Idle** | 形容词 | 空闲的（没有负载） | *The worker threads are currently **idle**.* |
| **Healthy** | 形容词 | 健康的（通过健康检查） | *The load balancer marks the pod as **healthy**.* |

#### 2. 进行中（In Progress）
| 术语 | 词性 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **Pending** | 形容词 | 待处理/挂起（排队中） | *The job is **pending** in the queue.* |
| **Processing** | 现在分词 | 处理中 | *The request is currently **processing**.* |
| **In Progress** | 介词短语 | 正在进行 | *The deployment is **in progress**.* |
| **Running** | 现在分词 | 正在运行（长期任务） | *The migration script is still **running**.* |

#### 3. 阻塞 / 等待（Blocked & Waiting）
| 术语 | 词性 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **Blocked** | 过去分词 | 被阻塞（等待资源/锁） | *The thread is **blocked** waiting for the lock to be released.* |
| **Waiting** | 现在分词 | 等待中 | *The request is **waiting** for a database connection.* |
| **Stalled** | 过去分词 | 停滞（不前进也不失败） | *The build has **stalled** without any error output.* |
| **Throttled** | 过去分词 | 被限流/被限制 | *Requests are being **throttled** due to rate limiting.* |
| **Queued** | 过去分词 | 已入队 | *The tasks are **queued** and will be processed later.* |

#### 4. 异常 / 失效（Faulty & Failed）
| 术语 | 词性 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **Failed** | 过去分词 | 失败（未完成） | *The deployment has **failed**.* |
| **Unavailable** | 形容词 | 不可用 | *The database is **unavailable** due to a network partition.* |
| **Degraded** | 过去分词 | 降级（功能受损但还在跑） | *The service is **degraded**; some endpoints are responding slowly.* |
| **Corrupted** | 过去分词 | 损坏（数据/文件） | *The cache file is **corrupted**. We need to rebuild it.* |
| **Stale** | 形容词 | 过时的/陈旧的（缓存/数据） | *The cache contains **stale** data.* |
| **Orphaned** | 过去分词 | 孤立的（失去父级） | *There are **orphaned** resources that were not cleaned up.* |
| **Panicked** | 过去分词 | 恐慌（程序崩溃前的状态） | *The service **panicked** and restarted.* |
| **OOMKilled** | 动词 | 因内存溢出被杀死（K8s 术语） | *The pod was **OOMKilled** due to high memory usage.* |

#### 5. 结束 / 清除（Done & Cleaned Up）
| 术语 | 词性 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **Completed** | 过去分词 | 已完成（成功结束） | *The batch job has **completed** successfully.* |
| **Resolved** | 过去分词 | 已解决（问题已修复） | *The issue has been **resolved**.* |
| **Closed** | 过去分词 | 已关闭（流程终结） | *The ticket has been **closed**.* |
| **Cleaned Up** | 动词短语 | 已清理（垃圾回收） | *The temp files have been **cleaned up**.* |
# 常用 `out-of-` 术语

| 分类 | 术语 | 核心含义 | 技术场景例句 |
| :--- | :--- | :--- | :--- |
| **资源/空间** | **Out-of-Memory (OOM)** | 内存耗尽（常指程序崩溃） | *The container was killed due to an **out-of-memory** error.* <br> （容器因为内存溢出错误被杀死了。） |
| | **Out-of-Space** | 磁盘空间不足 | *The backup failed because the drive was **out of space**.* <br> （备份因为磁盘空间不足失败了。） |
| | **Out-of-Bounds** | （数组/内存）越界 | *The program crashed with an **out-of-bounds** array access.* <br> （程序因为数组越界访问崩溃了。） |
| | **Out-of-Capacity** | 超出负载能力 | *The server returned 503 due to an **out-of-capacity** condition.* <br> （服务器因为超出容量限制返回了 503。） |
| **状态/流程** | **Out-of-Order** | 乱序（不按顺序） | *The messages were processed **out of order** on the consumer side.* <br> （消息在消费者端被乱序处理了。） |
| | **Out-of-Sync** | 不同步（数据/状态不一致） | *The replica set is **out of sync** with the primary node.* <br> （副本集与主节点不同步。） |
| | **Out-of-Date** | 过时（需要更新） | *The dependencies are **out of date**. We need to upgrade them.* <br> （依赖已经过时了，我们需要升级它们。） |
| | **Out-of-Service** | 停用/不提供服务 | *The load balancer marked the unhealthy instance as **out of service**.* <br> （负载均衡器将不健康的实例标记为停止服务。） |
| **逻辑/规则** | **Out-of-Scope** | 超出范围（不包括） | *That feature request is **out of scope** for the current sprint.* <br> （那个功能请求超出了当前冲刺的范围。） |
| | **Out-of-Gamut** | 超出色域（UI/图形） | *The color value is **out of gamut** for this display profile.* <br> （该颜色值超出了此显示配置文件的色域。） |
| **能力/水平** | **Out-of-Your-League** | 超出能力范围（习语） | *This task is a bit **out of my league**. I need to ask for help.* <br> （这个任务有点超出我的能力范围了，我需要求助。） |
| | **Out-of-the-Box** | **开箱即用的**（无需配置） | *The tool works perfectly **out of the box**.* <br> （这个工具开箱即用，效果非常好。） |
