# 时间连词/介词

## 1. when（连词）当…… 时候

可接**短暂动作或延续动作**；从句动作可以瞬间发生。

> Clean up resources when the component unmounts.
> 
> 组件卸载时清理资源。

## 2. while（连词）当…… 期间

从句必须是**延续进行的动作**，多用进行时态，强调主句和从句同时在发生。

> Do not block main thread while processing heavy tasks.
> 
> 处理繁重任务期间不要阻塞主线程。

## 3. during（介词）在…… 期间

后面接**名词 / 名词短语**，不接从句；描述在某段时间之内。

> Many exceptions occurred during startup.
> 
> 启动期间发生了许多异常。

## 4. throughout（介词）贯穿、遍及整个时间段

强调整个时间**从头到尾全部过程**。

> Keep the connection alive throughout the whole session.
> 
> 在整个会话全过程保持连接存活。

## 5. on（介词）在…… 之时

技术高频：**on + 名词（事件）**，一发生某事件就触发回调。

> Trigger callback on page load.
> 
> 页面加载时触发回调。

## 6. upon（介词）在…… 一发生就

和 on 含义接近，**更书面正式**，技术文档、面试书面表达优先。

> Upon receiving response, parse the payload.
> 
> 一旦接收到响应，就解析载荷。

# 易错介词
### 在栈中
**on** the stack, 不是in 

### 入栈/出栈
be pushed **onto** the stack / be popped **off** 

### 通过...访问
accessed **via** `window`或 accessed **by** name

### 在周五之前
**by** Friday, 不是before

### 百万级
capable of supporting read traffic **at** millions of QPS.
