# 克服中英文核心差异
尽管中英文思维存在诸多差异，但是即兴口语不必追求完美，重点是把这两门语言的主要差异克服掉，在这个基础上不断强化自己的高频词汇和句式库，并逐渐克服其它差异。

## 基础句式语序
### 主谓宾
## 基础公式
主语 + 谓语(动词居多) + 宾语(名词居多)
## 扩展公式
(句首状语) + 主语 + (左侧副词) + 动词 + (右侧副词1) + 宾语(名词居多) + (右侧副词2) + (状语) 

在主谓宾方面，中英文总体差距不大，主要区别在于:
1. 中文的状语一般都在谓语左侧或句首，不像英文大多放在句尾。
2. 中文的副词只能放在动词前面，没有英文那么灵活。
> 当修饰形容词时，中英文都只能放在形容词前面，例如highly hard(超级难)

### 主系表

## 基础公式
主语 + be + 形容词/名词
## 扩展公式
1. (句首状语) + 主语 + be + (副词) + 形容词 + (状语)
2. (句首状语) + 主语 + be + (冠词/量词) + (副词) + (形容词/组合形容词) + 名词 + (后置定语(可并列)) + (状语)

名词左侧的公式中英文差距不大，关键在右侧:
1. 后置定语，算是即兴表达的一大重难点。
2. 状语。

### 总结
对于基础句式，重点需要训练对**后置定语**和**状语**成分的即时识别与表达，以下是一些示例:

那个坐在角落里、一直在看手机的年轻人，是我表弟。
> 那个年轻人(坐在角落里、一直在看手机)，是我表弟。
> That young man sitting at the corner and looking at his phone all the time is my cousin.

这是我之前跟你提起过的那位很厉害的设计师。
> 这是那位很厉害的设计师(我之前跟你提起过的)
> This is the outstanding designer I mentioned to you before.

她选择了一个很少有人敢尝试的、极具挑战性的研究方向。
> 她选择了一个极具挑战性的研究方向(很少有人敢尝试的)。
> She selects a extremely challenging research direction few people dare to try.

那些不愿意接受变化的人，最终会被这个时代淘汰。
> 那些人(不愿意接受变化)，最终会淘汰(被这个时代)。
> Those who are unwilling to accept changes will be evicted by the era.

我们正在寻找一位能够流利使用三种语言、并且有海外工作经验的经理。
> 我们正在寻找一位经理(能够流利使用三种语言、并且有海外工作经验)
> We're looking for a manager who can speak three kind of languages fluently and has oversea experience.

## 主语问题
英文不像中文那样除祈使句外在很多时候都可以省略主语，为了克服这种中文思维，也需要进行刻意练习，一般的处理方法如下:

| 处理方式                              | 核心公式                               | 语体 / 使用场景                                     | 技术/文档场景示例                                                                         |
| :-------------------------------- | :--------------------------------- | :-------------------------------------------- | :-------------------------------------------------------------------------------- |
| **1. 被动语态**                       | `It is + 过去分词` 或 `名词 + is + 过去分词`  | **极正式/书面**，常见于技术文档、错误信息、系统提示。**强调动作，不强调执行者**。 | *The data **is stored** in Redis.* <br> （数据被存储在 Redis 中。）                         |
| **2. 虚拟主语 (It)**                  | `It is + 形容词/名词 + to do / that...` | **中性/通用**，常用于说明“做某事是...的”。                    | ***It** is recommended to use HTTPS in production.* <br> （建议在生产环境中使用 HTTPS。）      |
| **3. 真实主语 (We / You)**            | `We/You + 动词原形`                    | **口语/非正式**，常见于团队内部沟通、代码注释、教程（You）。            | ***We** need to restart the service.* <br> （我们需要重启服务。）                            |
| **4. 泛指主语 (Someone / Something)** | `Someone / Something + 动词原形`       | **口语/泛指**，常用于描述“有人做某事”或“出了某事”。                | ***Someone** should review this PR before merging.* <br> （合并前，应该有人 review 这个 PR。） |

## 名词思维
相比中文，英文是一门更加静态的语言，优先使用名词并省略动词，这样可以让语言更加简洁。
例如: 由于连续下了好几天雨，该如何表达？
1. 由于 => Due to
2. 主语: 连续的雨(省略"下了") => continuous rain
3. 状语: 好几天 for many days

# 即兴技巧
1. **简单**: 优先使用简单熟悉的词汇和句式(例如短句)，不一定要最合适的。
2. **省略**: 有时可以省略次要/多余部分，不是每个词都需要表达出来，只要核心意思表达出来就行。
3. **转换**: 有时可以转换思维，不强行直译，意思相近就行。
最后需要说明，即兴表达不要追求无错误甚至完美，试想下你用母语即兴表达都不能保证，何况外语！

## 词汇和句式库
整理一份高频词汇和句式的资料随时复习，查阅和扩充。
即兴表达中常用到的陈述句句式:

| 句式                                                                                 | 写法                                                                                 | 语感                 | 适用场景                                    |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------ | --------------------------------------- |
| 1.with + 包含<br>2. which/that + 补充 <br>3. for + 目的<br>4. in + 位置<br>5. where + 抽象定义 | Redis is an in-memory store with persistence and high throughput.                  | 像字典定义，简洁、客观。       | 最适合下定义，在核心名词后附加属性。                      |
| **分句拆分**                                                                           | Redis is an in-memory store. It persists data to disk and handles high throughput. | 像教学讲解，舒缓、清晰。       | 当信息量较大，或想强调某个点，拆开增加呼吸感。                 |
| **并列谓语**                                                                           | Redis stores data in memory, persists to disk, and handles high throughput.        | 像功能清单，强调它“能做这几件事”。 | **最推荐**，描述流程或功能集时最地道。                   |
| **双谓语（现在分词）**                                                                      | Redis is in-memory, providing high throughput and optional persistence.            | 像架构决策，强调因果关系。      | 主句是主动语态、且主语是施动者时使用，需警惕垂悬修饰语陷阱。          |
| **同位语结构**                                                                          | Redis, an in-memory data store, provides persistence and handles high throughput.  | 像插入式解释，流畅不打断主句。    | 当名词需要**重定义**或**附加关键属性**时，例如带别名/简称的复杂定义。 |
即兴表达中常用到的时态:

| 你在心里想表达的意思 | 英语即兴应选时态               |
| ---------- | ---------------------- |
| 客观事实、习惯    | 一般现在时                  |
| 现在正在发生     | 现在进行时                  |
| 过去发生且已结束   | 一般过去时                  |
| 已经完成，有影响   | 现在完成时                  |
| 持续到现在      | 现在完成进行时                |
| 将来计划或预测    | `be going to` / `will` |

# 总结: 即兴表达中需要处理好的问题
1. 后置定语和状语成分的识别与后置表达。
2. 名词思维和主语补全。
3. 优先使用简单熟悉的词汇和句式。
4. 表达困难时，运用省略和转换。
5. 不断升级自己的即兴高频词汇/句式库。
## 口诀
1. **主干先行** → 排除后置修饰(可能需补主语)
2. **后挂右移** → 长的修饰放名词后面，方式/地点/时间往右放
3. **卡壳降级** → 从句→拆句；难词→换/省

# 即兴口译

我上周遇到了一位很有意思的设计师。她曾在日本工作过三年，对极简主义风格有很深的理解。我们聊了很久，最后她答应帮我设计新家的客厅。

I met a very interesting designer last week. She, who worked in Japan for three years, has a deep understanding about minimalism. We talked for a long time, and finally she agreed to help me design the living room of my new house.

### Step1: 我上周遇到了一位很有意思的设计师

读完迅速分辨出需要后置的状语/定语，其它部分按直线思维表达即可。

 => 我遇到了一位(很有意思的)设计师(上周)

I met a very interesting designer last week.

### Step2: 她曾在日本工作过三年

主谓: 她曾工作过
地点状语: 在日本
时间状语: 三年

 => 她曾工作过(在日本)(三年)

She (once) worked in Japan for three years

### Step3: 对极简主义风格有很深的理解

 => 有很深的理解(对极简主义风格)

这句是对上一部分的补充说明，涉及到复杂陈述句句式。

1. 介词(含关系代词)结构: with a deep understanding about minimalism.
2. 分句拆分: She has a deep understanding about minimalism.
3. 并列谓语: has a deep understanding about minimalism.
4. 双谓语: having a deep understanding about minimalism.
5. 同位语(不推荐用在口语中): She, who worked in Japan for three years, has a deep understanding about minimalism

### Step4: 我们聊了很久

 => 我们聊了(很久)
 
We talked for a long time.

### Step5: 最后她答应帮我设计新家的客厅

这里需要用到逻辑衔接词finally，最好前面加上and让衔接更顺畅。

 => 最后她答应帮我(设计新家的客厅)

and finally she agreed to help me design the living room of my new house.

## 总结
1. 每读完一句话(包含完整的基础结构)，在大脑中立即分离将定语/状语后置，按直线思维表达完前面部分再表达后置部分。
2. 当遇到复杂陈述句时，优先用介词结构，或者并列谓语/双谓语，分句拆分可以作为最后的兜底。
3. 另外需要注意对逻辑衔接和主语缺乏的处理。
4. 可选: 练习完所有句子后，再整段话一口气练习或复述一遍。

最后: 目前先这样练，等足够熟练后，再练习读完一段，口译一段。

### 哪些部分需要明显后置？
1. that/which/who: 
	1. 是什么/谁，是怎么样的，做什么(优先使用现在分词/过去分词/形容词短语)；
	2. 完整从句(that/which/who不可省略)
2. for: 表对象和原因
3. to: 表对象或目标
4. with: 表伴随或工具
5. about: 表关于或针对
6. where: 表抽象定义或地点说明
7. 方式状语
8. 地点状语
9. 时间状语
