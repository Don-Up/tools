# 主系表
## 基础公式
主语 + be + 形容词/名词
## 扩展公式
1. 主语 + be + (副词) + 形容词 + (状语)
2. (句首状语) + 主语 + be + (冠词/量词) + (副词) + (形容词/组合形容词) + 名词 + (后置定语(可并列) + (状语)
# 形容词与后置定语
当练习口译时，后置定语在中文中的位置相对于形容词来说，一般要更靠前一些，例如:

这是<他写过的><所有小说中>(最受欢迎的)一本。
> _This is the most popular one among all the novels he has ever written._

如果修改下顺序: 这是最受欢迎的所有小说中他写过的一本，就会显得很不自然。

但是如果是即兴表达没有现成的中文句子该如何处理？
1. "最受欢迎的"作为形容词，可以很容易识别出来。
2. "所有小说中"和"他写过的"都用于限定范围，总体来说这两个范围不容易区分宏观微观，哪个先来都没太大关系。在即兴表达中，不要过分关注后置定语的顺序，最关键的是快速区分形容词和后置定语，并将它们表达出来。
## 思维扩展
1. 汤姆是一只猫: Tom is a cat.
2. 汤姆是一只蓝色的猫: Tom is a blue cat.
3. 汤姆是一只深蓝色的猫: Tom is a dark-blue cat.
4. 汤姆是一只爱跳舞的深蓝色的猫: Tom is a dark-blue cat loving dance.
5. 汤姆是一只爱在晚上跳舞的深蓝色的猫: Tom is a dark-blue cat loving dance at night.
> 在即兴表达中，关系代词能省则省，并使用更加简洁的现在分词/过去分词/形容词短语/介词的形式。

总结: 在即兴表达主系表结构时，要迅速识别并避开脑海中要表达的复杂定语和状语部分，先说出主语 + be + (冠词/量词) + (副词) + (形容词/组合形容词) + 名词，再说出(后置定语) + (状语)。

# 主谓宾
## 基础公式
主语 + 谓语(动词居多) + 宾语(名词居多)
## 扩展公式
(句首状语) + 主语 + (左侧副词) + 动词 + (右侧副词1) + 宾语 + (右侧副词2) + (状语) 

## 思维扩展
1. 汤姆跳舞: Time dances.
2. 汤姆兴奋地跳舞: Time dances excitedly.
3. 汤姆兴奋地在房间里跳舞: Time dances excitedly in the room.
4. 晚上，汤姆兴奋地在房间里跳舞: Time dances excitedly in the room at night.
5. 晚上，汤姆兴奋地在一个宽敞的布满鲜花的房间里跳舞: In the evening, Time dances excitedly in the spacious room with flowers.
> 有时，一些状语信息也可以放到句子开头，作为重要背景。

总结: 表面上看，主谓宾相对于主系表要简单很多，但是它可以嵌套主系表来实现更为复杂的结构，因此需要重点掌握好主系表的即兴表达能力。

另外，动词的变化也是一大重点，以下列举一些在日常交流中常用到的句式:
1. 汤姆跳舞 => Tom dances
2. 汤姆跳了舞 => Tom danced
3. 汤姆将要跳舞 => Tom is going to dance.
4. 汤姆已经跳了舞 => Tom has (already) danced.
5. 汤姆一直在跳舞 => Tom has been dancing / Tom keeps dancing / Tom always dances.
6. 汤姆从未跳过舞 => Tom has never danced.

思路:
1. 可选: 将一些重要的背景信息前置。
2. 描述主语(有可能涉及名词修饰)。
3. 谓语与修饰，副词优先放到右侧/末尾，跟中文习惯一致，状语放到右侧。
4. 描述宾语(有可能涉及名词修饰)。

> 名词修饰公式: (冠词/量词) + (副词) + (形容词/组合形容词) + 名词 + (后置定语) + (状语)

副词修饰动词时，位置比较灵活，但“句末”是最安全、最通用的落脚点。动词左侧用来强调频率和程度，动词右侧和句末则更偏口语化和自然。但当修饰形容词时，必须放在左侧。

| 位置          | 语感                       | 典型副词          | 示例                                |
| ----------- | ------------------------ | ------------- | --------------------------------- |
| **左侧**（动词前） | 副词是句子的**核心焦点**，强调动作的“特质” | 频率词、程度词、短方式副词 | _He **always** comes late._       |
| **右侧**（动词后） | 副词修饰动作的**具体方式**，是描述的一部分  | `-ly` 方式副词    | _He speaks **fluently**._         |
| **句末**      | 副词是**附加信息**，补充背景，权重最低    | 地点、时间、长方式副词   | _He speaks English **fluently**._ |
