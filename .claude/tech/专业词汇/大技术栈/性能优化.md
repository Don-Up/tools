### 动词搭配速查（性能优化场景的高频动作）

| 动作 | 常用搭配 | 例句 |
| :--- | :--- | :--- |
| **Reduce** | latency, response time, payload, bundle size | *We **reduced** latency by 30%.* |
| **Improve / Boost** | performance, throughput, response time | *This change **boosted** throughput by 2x.* |
| **Cut / Shave off** | load time, response time | *We **cut** load time from 3s to 800ms.* |
| **Spike / Surge** | latency, response time, traffic | *Latency **spiked** during the traffic surge.* |
| **Drop / Fall** | response time, error rate | *The error rate **dropped** to near zero.* |
| **Add / Apply** | caching, indexing, throttling | *We **added** caching to the API layer.* |
| **Remove / Eliminate** | bottlenecks, blockers, dead code | *We **eliminated** the database bottleneck.* |
| **Offload** | assets, computation, traffic | *We **offloaded** static assets to a CDN.* |
| **Scale** | horizontally, vertically | *We need to **scale** the service horizontally.* |


### 快速决策流（0.5 秒选择）

你想描述性能优化相关的内容？

- 某个指标**太高了，要降低**？
  - 用 **Reduce / Cut / Shave off** + latency / load time / payload
  - 例：We need to reduce the TTFB.

- 某个指标**突然升高了**？
  - 用 **Spike / Surge** + latency / error rate / traffic
  - 例：Latency spiked to 5 seconds.

- **缓存相关**？
  - 命中用 **Cache Hit**，未命中用 **Cache Miss**，有效期用 **TTL**
  - 例：We set a TTL of 5 minutes.

- **前端加载相关**？
  - 用 **Lazy Loading** / **Async Loading** / **Minification** / **Tree Shaking**
  - 例：We implemented lazy loading for images.

- **数据库相关**？
  - 用 **Slow Query** / **Indexing** / **Connection Pool**
  - 例：We added an index to speed up the query.

- **代码优化相关**？
  - 用 **Refactoring** / **Debouncing** / **Throttling**
  - 例：We applied throttling to the scroll handler.


### 技术场景组合示例（性能优化的完整描述）

> *We identified a **bottleneck** in the API layer. The **p99 latency** was **spiking** to 2 seconds due to a **slow query**. We **added** a **database index** and **switched** to **non-blocking** I/O. We also **offloaded** static assets to a **CDN** and **implemented** **lazy loading** for images. After these changes, the **response time** **dropped** by 60%, and the **cache hit rate** **increased** to 95%.*

> （我们发现了 API 层的一个**瓶颈**。**p99 延迟**因为一个**慢查询**而**飙升**到了 2 秒。我们**添加**了**数据库索引**，并**切换**到了**非阻塞** I/O。我们还把静态资源**卸载**到了 **CDN**，并**对图片进行了懒加载**。经过这些改动，**响应时间**下**降**了 60%，**缓存命中率**上**升**到了 95%。）
