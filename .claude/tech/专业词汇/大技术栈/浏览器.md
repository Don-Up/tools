### 深度拆解 + 避坑指南

#### 1. DOM vs CSSOM vs Render Tree（三棵树的关系）
| 树 | 来源 | 用途 |
| :--- | :--- | :--- |
| **DOM** | HTML | 文档结构 |
| **CSSOM** | CSS | 样式信息 |
| **Render Tree** | DOM + CSSOM（不含 `display:none`） | 实际渲染的内容 |

- **技术场景**：*The browser builds the DOM and CSSOM separately, then combines them into the render tree.*

#### 2. Reflow vs Repaint（回流与重绘的区别）
| 操作 | 触发原因 | 性能开销 |
| :--- | :--- | :--- |
| **Reflow** | 几何变化（宽高、位置、字体大小） | 高（重新计算布局） |
| **Repaint** | 视觉变化（颜色、透明度） | 低（只重新绘制像素） |

- **技术场景**：*Avoid frequent reflows by batching DOM changes. Use `transform` and `opacity` for animations because they skip reflow and repaint and go straight to compositing.*

#### 3. LocalStorage vs SessionStorage vs Cookies
| 特性 | **LocalStorage** | **SessionStorage** | **Cookies** |
| :--- | :--- | :--- | :--- |
| **容量** | 5-10MB | 5-10MB | 4KB |
| **持久性** | 永久（手动清除） | 标签页关闭清除 | 根据 Expires 设置 |
| **跨域发送** | 否 | 否 | 是（自动随请求发送） |
| **访问** | JavaScript | JavaScript | JavaScript / 服务器 |
| **适用场景** | 用户偏好设置 | 临时表单数据 | 会话管理、认证 |

- **技术场景**：*Use LocalStorage for long-term data, SessionStorage for temporary data, and Cookies for authentication.*


### 快速决策流（0.5 秒选择）

你在进行前端开发时——

- **检查页面结构/样式**？
  - 查看/编辑 DOM → **Elements Panel**
  - 查看 CSS 样式 → **Computed / Styles** 面板

- **调试 JavaScript**？
  - 查看日志/错误 → **Console**
  - 设置断点/步进调试 → **Sources Panel**
  - 监听点击/输入事件 → **Event Listeners** 面板

- **分析网络请求**？
  - 查看请求详情/响应 → **Network Panel**
  - 检查接口耗时 → 查看 **Timing** 列
  - 模拟弱网环境 → 切换 **Network Throttling**

- **分析和优化性能**？
  - 记录运行时性能 → **Performance Panel**
  - 检查页面加载指标（FCP/LCP/CLS）→ **Lighthouse**
  - 检查内存占用/泄漏 → **Memory Panel**
  - 分析打包体积 → **Coverage** 面板（或外部工具）

- **排查渲染异常**？
  - 元素重叠/错位 → 检查 **Layout / Box Model**，查看是否触发了 **Reflow**
  - 动画卡顿 → 在 **Performance** 面板中查看帧率（FPS）
  - 样式不生效 → 检查 **CSS Specificity** 和 **Computed** 面板

- **检查运行环境/兼容性**？
  - 查看 UA 信息 → `navigator.userAgent`
  - 检查功能支持 → `'caches' in window` 等方式进行**特性检测**
  - 调试移动端 → 开启 **Device Toolbar** 并切换 UA
