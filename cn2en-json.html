操作提示

  • Ctrl+V
  • 粘贴 JSON 数据
  • ← →
  • 上 / 下一条
  • review pre
  • 开启后:→ 先看上一句中文,↓ 看英文,再按 → 才跳下一条
  • 1 2 3
  • 切换 Mode
  • 4 5 6
  • 切换 单句 / 连续 / 循环
  • 7
  • 切换 无限循环(一直读当前这句)
  • ↓
  • 揭示英文 / 笔记
  • ↑
  • 隐藏 / 显示下面的大字英文(上面的小字英文跟着一起)
  • Space
  • 暂停 / 继续朗读
  • E
  • 读当前英文
  • Z
  • 读全文
  • R PgDn
  • 读 EN
  • N
  • 添加笔记
  • F
  • 收藏当前条
  • Alt+F
  • 打开收藏夹
  • Ctrl+F
  • 读剪贴板里的标题,直接加载数据库里对应的那份 JSON(对不上会提示)
  • Alt+R
  • 读全文 / 循环读选中文本
  • Alt+A PgUp
  • 分句跟读 (按 , — : ; . ? ". 分句)
  • A Del
  • 再次朗读当前分句 (基于上次 Alt+A)
  • Alt+S
  • 分句跟读模式下循环朗读选中分句
  • 单句 / 连续 / 循环
  • 单句:R 读一次后停;连续:R 读完一句后自动跳到下一句,末句后回第一句;循环:无限循环当前句 (Mode 3 旁)
  • 随机
  • 开启时每次朗读随机挑选一个英文语音 (循环 右侧)
  • 离开即停
  • 开启后切到别的标签页 / 窗口时自动停止朗读 (review pre 右侧)
  • 念时藏中文
  • 开启后朗读时自动把中文句子藏起来,读完自动放回来 (离开即停 右侧)
  • Alt+H
  • 隐藏 / 显示中文句子
  • Alt+L
  • 难句复习(列表在上,输入框在下)
  • 小字英文
  • 中文上方的小字英文,点一下能改写(可以带 HTML 标签, 粗体显示成橙色;写 [[基词]]注音}} 可以加注音,注音浮在词上面);编辑时看到的是源码(标签原样),点外面才渲染成样子;改的存进每条数据的第三格,不影响 JSON 原文;Mode 1 常显,Mode 2 / 3 跟着下面的英文一起显隐
  • Alt+J
  • 编辑 JSON
  • Ctrl+I
  • 设置背景
  • Alt+2
  • 为选中中文添加注释
  • Alt+3
  • 选中中文标记为删除线(需先收藏)
  • Alt+4
  • 选中中文包裹为 <small> 小字(需先收藏)
  • Alt+1
  • 显示 / 隐藏此帮助
